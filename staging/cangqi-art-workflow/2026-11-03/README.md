# 苍岐美术生产与演出交接工作流

本包基于 2026 年 11 月 3 日的四个工作区快照，供合回现有苍岐项目使用。先按本次要办的事进入对应章节。

| 要办的事 | 入口 | 从哪里接着办 |
| --- | --- | --- |
| 从原文做演出、登记需求、处理构图变更 | [演出册](Cangqi-ArtLab/docs/苍岐演出与美术统一规则.md#stage-start) | 看 [CURRENT](AVGStudio/CURRENT.md) 的本场状态，使用原有 04／05 模板 |
| 调度人物资产、确认角色定版 | [美术册 A5](Cangqi-ArtLab/docs/苍岐美术生产规则.md#art-early) | 把该角色适用的身份、衣装与首张样板一次送用户，按收到的版本回执恢复后续生产 |
| 做有场所构图的背景、CG 或同机位状态变体 | [空间白模 S0–S7](Cangqi-ArtLab/docs/苍岐美术生产规则.md#art-spatial) | 从已登记的总体平面和组成设计出发。首次建模走计划机位，回填实测机位后再做结构图和成图 |

| 安装或调用随包工具 | [工具用法](Cangqi-ArtLab/config/工具用法.md) | 空间白模用 Three.js。已有 ComfyUI、Qwen 2509、Forge、PosePipeline 和资产工作台沿用项目环境 |

## 合入本机

将四个同名目录按原相对路径合入现有工作区。两本规则书及工具手册是一组；工单模板和两个初稿模型的提示词需随组更新。[文件清单](MANIFEST.md)列有基线、修改范围和文件指纹。保留本机较新的场次进度与其他未提交改动；第一场院落纠正事项记在 CURRENT 的待办中，实际绑定及状态由本机回读。

首次在本机使用时，从既有工作台读取一张设计版本，核对新版本说明、用户回执的备注和下游绑定可正常读写，再生成一份角色定版包或一场的交接包。已有本地配置优先；试点的 Qwen API 图谱、模型权重及正式生产数据均属于原项目运行环境。
