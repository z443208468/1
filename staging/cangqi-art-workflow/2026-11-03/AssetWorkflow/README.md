# AssetWorkflow

AssetWorkflow 连接 Novel2Galgame 的演出稿、资源库和美术生产工单。苍岐使用与工作台相同的 PocketBase 业务库，原 SQLite 资产快照只读。其他项目按自身配置连接存储。章节流水线的 SQLite 运行数据库与资产库分别管理。

## 输入与输出

| 输入 | 模块提供的记录 |
| --- | --- |
| 项目、内部段、章节原文和演出步骤 | 实体目录、原文单元、场景工单、步骤与工单／资源／设计版本的关联 |
| 实体及设计图、版本说明和参考文件 | 实体 ID、版本号、设计文件及引用。人物和服饰可分别管理。 |
| 已审素材需求、设计决定与工单正文 | 工单状态、负责的资源、依赖、绑定的实体及具体版本、下一动作 |
| 工作台上传的图像版本、采纳状态与工单附件 | 成图路径、文件指纹、采纳版本与工单附件的回填结果 |

项目配置和任务目录在 `projects/<project_id>/`。项目的 `config.json` 指定演出稿、需求位置与工作台接口地址。已有 Novel2Galgame 资源 ID 和实体 ID 各自保留，并通过工单建立映射。模块记录和读取数据，内容是否可复用、设计或图像是否通过由对应规则书裁决。

## 工作入口

- 项目进度读取本机 `AVGStudio/CURRENT.md` 顶部的当前场。演出设计及登记按[苍岐演出规则](../Cangqi-ArtLab/docs/苍岐演出与美术统一规则.md)，字段见“美术交接字段契约”。
- 美术领取已登记工单后按[苍岐美术生产规则](../Cangqi-ArtLab/docs/苍岐美术生产规则.md)，按工单类型进入 A0 所列工序。
- 查询、实体与版本登记、用户审核记录、采纳、附件及回填均见[工具用法](../Cangqi-ArtLab/config/工具用法.md)。工单说明按[设计工单模板](templates/design-task.md)或[成图工单模板](templates/render-task.md)填写。
