# R7交付审阅与证据范围

本文件定义本次交付实际要满足的范围。当前机器结果以同目录JSON为准，每份结果必须绑定当前源码；PDF以最终三文件的SHA和实际页图为准。最终打包后另写交付状态摘要，不把这里的要求误当已经执行。

## 1. 各证据分别证明什么

|证据|能证明的范围|不能替代的检查|
|---|---|---|
|mechanics_results / verify_mechanics|原卡片、字段、答案、分支与引擎图形一致|新故事是否好玩|
|logic_results|纯逻辑检查、解空间枚举与原规则|实际浏览器渲染|
|browser_results|当前离线文件的通关、早解、保存、导入、分支和异常行为|实地可达性|
|narrative_results|当前双语分镜、窄屏、提示、收据剧透边界等指定行为|人物是否感人|
|content_audit|双语结构、必要正文与源数据完整性|真实游客理解|
|pdf_results|最终PDF页数、文本与生成参数等|逐页视觉检查和实体裁切|
|PDF_VISUAL_REVIEW|实际被查看的最终页图、SHA和发现/修正|物理印刷手感、天气适应|
|release/package_verification|最终压缩包实际解压、逐文件校验|在线销售或商业许可|

## 2. 本轮内容审查

非正文作者的AI结构审查读了开场、五关、六幕、纸面动作与早解路径，实际指出并修复特定记录/演示的证据关系、S05交易、早解行为假定和摄影下界的措辞。报告保留审查范围、修正过程及最终正文哈希。

该审查者曾讨论候选，不能称完全盲审；它不是目标游客或用户的认可。结论仅为可进入并交付完整可玩原型，没有宣称“游客必然觉得有趣”。
