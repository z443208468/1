## 2. 八条可执行原则

| 原则 | 原文支持与边界 | 本项目执行方式与退回条件 |
|---|---|---|
| **1. 每个动作必须改变可理解的局面。** | Nicholson将有意义的行动与可辨认结果、整体任务联系起来；并不要求写大量剧情。 | 每一步写成“观察什么→作出什么判断/操作→排除了什么/获得什么”。若动作只为收一个无关数字，删去后仍能做同样推理，退回。 |
| **2. 环境必须参与推理，不能只提供包装。** | Nicholson要求挑战与所在世界、环境一致；这一点本身还不足以证明地点不可替代。 | 做迁移测试：把景点名、照片和数值换掉，玩法是否原封不动成立？若成立，需说明实物形状、空间关系或观察方式究竟改变了哪一步解法。无法说明则退回。此“迁移测试”是项目判据。 |
| **3. 让玩家决定怎样验证，而非猜作者想要哪一步。** | Alexander区分准备情境与强行预定玩家事件序列；原文适用有GM的TRPG。 | 可接受固定步行路线，但站内要有可比较的假设与可验证证据；不能靠猜某个词、盲选某张卡才显示关键事实。自助游戏必须预先写清合法操作及等价解法。 |
| **4. 关键进展要有防卡死结构。** | Three Clue Rule建议一个重要结论有多条可发现线索，目的在于容错；不是要求玩家集齐三个物品。 | 先列关键结论，再列独立证据/定位提示/兜底路径。区别“多证据共同约束唯一答案”和“多条路径抵达同一结论”。同一块牌子的三张照片不算三条独立路径。所有线索都必须收齐才开门，会制造额外瓶颈。 |
| **5. 难度应主要来自解释与操作，不来自关键材料拿不到。** | GUMSHOE取消必需线索的随机骰检，但保留合理调查行动；不是一进场就把答案交给玩家。 | 提供清楚搜索边界、可读材料和必要翻译；让难点留在关系推理、模型操作、辨别条件。文字模糊、室内关闭、无许可物品或随机路人不能成为必经解法。 |
| **6. 误判必须能被证据纠正。** | Nicholson区分题目范围内的干扰与让玩家白忙的无意义假任务。 | 每个备选答案给出能在现场或道具上检查的差异。错误操作要留下可识别的不一致；“答案错了，请重试”不够。无证据反驳的诱饵、靠无限试选项过关、凭作者隐藏规则才能淘汰的答案，退回。 |
| **7. 走动、折叠、组装和合作应产生信息作用。** | SciSpace返回的地点游戏、实体交互与合作论文提供研究线索；本次只读取摘要，不能保证某种操作必然有效。 | 对每项实体动作做删除测试：取消换位置、取消折纸、由一人照抄，推理是否仍完全相同？若完全相同，该动作只是仪式。操作至少应改变可见关系、约束组合、验证方法或成员掌握的信息之一。不要用强制分头跑远、互相遮挡必要材料制造合作假象。 |
| **8. 提示、节奏和终局复用要在设计时可检查，体验仍须盲测。** | 三线索与GUMSHOE支持避免瓶颈；Nicholson支持任务之间有意义的联系。下列具体做法是项目推导，非文献给出的保证。 | 提示按“看哪里→注意什么关系→下一步怎么做→完整解释”分层；每站记录预计操作、推理与步行负担，避免五站同一动作。终局若存在，应让之前学到的关系/工具再次参与新推理，不能只拼五个答案。审稿能验证闭合性，不能冒充真实新手完成时长或乐趣评分。 |

## 3. TRPG原则的迁移边界

本项目可以继承TRPG的证据解释、有效选择、合理行动与多路径容错；**不需要增加人物数值、掷骰、战斗轮次或主持人**。这些系统元素只有在确实改善用户当前体验时才值得采用。

自助街头游戏没有GM随时识别合理替代答案。因此每站交稿必须明确：玩家初始信息、允许动作、全部必要材料、关键结论、答案证明、至少两种常见误解怎样被纠正、提示及无法观察时的处理。若只写“主持人看情况给线索”，设计没有闭合。

街道天然含有大量与游戏无关的符号，必须把观察区域说清楚。游戏不能让人误以为需要进入未开放场所、触摸展品、移动公共设施或找工作人员配合。这些是具体可执行性要求，不是用安全口号替代游戏设计。

## 4. 单站送审时必须交付的证据

1. **一段人话玩法**：玩家拿到什么，在现场做什么，产生何种新认识，如何知道自己做对。
2. **媒体证据表**：关键条件对应照片文件或视频时间点；区分直接看见、合理推断、尚未证实。
3. **完整解题演示**：从不知答案开始，逐步用给出的材料推出结果；不能跳过“显然应该这样折/这样读”。
4. **不可替代说明**：该场景的哪项组合关系决定了操作或答案；替换地点后具体哪一步失效。
5. **误解与提示**：最可能的错误理解、可观察的纠正信号、逐级提示；不能只列设计者想象的理想路径。
6. **审核结论的范围**：可标为“纸面机制审查通过”；在没有陌生玩家现场盲测之前，不标“体验已验证”“达到商业产品实测水平”。

## 5. 本研究不能替项目证明的事

- 理论引用数量不能证明一关好玩；折纸、视角或多层信息也不自动等于好玩法。
- 五站互不重复并不意味着每站都成立；仍需逐站核实场景实物和答案。
- 学术论文或设计者文章不能证明本项目与《魔都迷踪》同等质量。该比较需要该产品可核实机制与本项目实际表现，独立审核应另列已知与未知。
- 本次未进行现场勘测、制作实体道具、玩家盲测或统计研究。任何预计时间与难度都应标“设计预估”。
