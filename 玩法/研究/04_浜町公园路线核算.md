# 浜町公园：修订路网巡回题组合核对

日期：2026-10-22。用途：核对主设计者根据媒体审核修订的选定路网、合格路线、失败路线与重复次数下界。不是现场通行认证，也不代替独立游戏性审核。

**本次完全删除已被媒体否决的C—E北侧绕行。旧图及旧13步路线不作为本次通过证据。**使用儿童区靠楼内侧与靠道路外侧两条不同步道。下文的边数是纸上游戏选定路段数，不表示真实距离、耗时或无障碍等级。

## 1. 节点与边：本题选用图，不是整个公园道路全集

|节点|代表位置|
|---|---|
|P|图下方圆形广场|
|W|草地图左下路口|
|A|草地图左上、池图左端对应路口|
|C|体育中心图左上、池图右侧对应路口|
|B|体育中心图左下地面入口外对应路口|
|D|儿童区图下端|
|E|儿童区图上端|
|F|玩家依据现场菱形立面确认的观墙节点；是选定白色步道上的观察位置，不锁定勘测照片的精确摄影点|

固定七段：**PW、WA、AC、CB、BP、WB、BD**。

D—E之间有两条独立路：

- **I：靠体育中心的内侧步道。**
- **O：靠道路的外侧步道。**

正确终点F插入I，I分成DF_I、FE_I；O仍是DE_O。故正确题图共十段：

`PW, WA, AC, CB, BP, WB, BD, DF_I, FE_I, DE_O`

内外两条D—E步道不是同一条路画了两遍；各走一次不消耗重走券。制图时必须将两条路明确分开，不能在E、D之外画出不存在的连接。

## 2. 玩家规则必须明确的几项

1. 从P出发，最后停F，所有十条选定路段至少经过一次。
2. 每段第一次经过不用券；每多经过一次用一张券，方向相同或相反都计。最多三张，不要求用完。
3. 经过路口多次本身不收券；只有重复路段才收券。
4. 可以中途经过P或F，完成全部路段后再停F。若把第一次到F理解为必须结束，这种中段终点题会被错误限制。
5. 玩家目标是找到不超过三张的合格路线。最优下界供设计审核使用，**不要要求在两个未确认的候选终点间比较哪个更省来决定F**，地点要由现场确定。

券名宜用“重走券”；“回头券”容易让人只计算原路反向走，漏算同向再次经过。

## 3. 正确终点：二券方案

节点顺序：

**P → W → A → C → B → P → W → B → D → E → F → D → F**

其中D→E走O，E→F及F→D走I。

逐段顺序：

`PW, WA, AC, CB, BP, PW, WB, BD, DE_O, FE_I, DF_I, DF_I`

共12步，覆盖十段；PW重复一次，DF_I重复一次，合计**二张**。

注意最后F→D→F确实原路往返，但第一次F→D是在补完尚未走过的内侧下段，第二次才收费。不能看到“回头”就把两次都计为重复。

## 4. 正确终点：另一条三券合格方案

**P → W → A → C → B → P → B → W → B → D → E → F → D → F**

其中D→E走O。

逐段顺序：

`PW, WA, AC, CB, BP, BP, WB, WB, BD, DE_O, FE_I, DF_I, DF_I`

共13步，覆盖十段；BP、WB、DF_I各重复一次，合计**三张**。这不是最优路线，但满足题面，因此应接受。

这也说明题目不能把唯一讲解路线当成唯一正确解。

## 5. 错误终点BC：三券数学上合格，但地点错误

若把F错误插在CB，则CB分成CF、FB；儿童区I不再分段，与O一起构成两条不同的DE边。

错误地点的十段图：

`PW, WA, AC, CF, FB, BP, WB, BD, DE_I, DE_O`

完整可行路线：

**P → W → A → C → F → B → P → W → B → D → E → D → B → F**

D→E走I，E→D走O。

逐段顺序：

`PW, WA, AC, CF, FB, BP, PW, WB, BD, DE_I, DE_O, BD, FB`

共13步，覆盖这个错误终点图的十段；PW、BD、FB各重复一次，合计**三张**。

这条路线不能被预算规则排除。它必须由现场证据排除：目标菱形立面位于儿童区靠体育中心一侧，而不是所误放的草坪一侧CB。玩家需要确认建筑哪一面具有目标特征，不是因为数学上“好走”就自行换终点。

**两个候选终点都存在三券以内路线，所以仅凭预算无法唯一推断F。**玩家材料不得预先把正确侧写成“儿童区答案”，也不得把“最省的候选侧”作为选址规则。

## 6. 四券诱惑失败方案

正确终点图下：

**P → W → A → C → B → P → B → W → B → D → E → D → F → E → F**

D→E和E→D均走O；D→F→E→F均在I。

逐段顺序：

`PW, WA, AC, CB, BP, BP, WB, WB, BD, DE_O, DE_O, DF_I, FE_I, FE_I`

共14步，全部覆盖，却使用**四张**：BP、WB、DE_O、FE_I各重复一次。

诱惑在于逐项补漏：绕完草地回P后先朝B走，再回补WB；到E后又沿外路退回D，才去补内路。每个局部动作都可以做，但累计重复超预算。把儿童区的两条路当成可以组成一个小环，而不是每次到尽头就沿同一条退回，能减少不必要重走。

## 7. 下界：为什么正确最少二张，错误地点最少三张

此段供设计与审核，不要求游客学习图论。

在两个版本中，原始十段路网只有W、D是奇度节点。要一笔从P走到F，最终P、F必须成为奇度，W、D必须变为偶度。因此重复路段需要改变P、F、W、D这四个节点的奇偶性。

### 正确终点图

每额外走一条边只改变两个端点的奇偶性，故一张券不可能同时修正四点，至少二张。重复PW与DF_I恰好修正四点；上面的12步路线给出实际构造。因此最少二张。

二张时可行的重复集合只有PW＋DF_I。重复集合唯一不表示完整行走顺序唯一。

### 错误终点图

仍须修正P、F、W、D。若只允许额外两条边，必须用两条不共端点的边正好配成这四点；在该图中只有PW是它们之间的直接边，DF没有直接边，其他配对也没有。故二张不够。

重复PW，再重复D—B—F两段，共三张，完成奇偶修正；上面的13步路线提供实际构造。因此最少三张。
