# 东京五站实景玩法设计

本目录执行2026年10月22日的新要求：只设计玩法；不沿用R9剧情，不开发程序。五站为纽扣博物馆外、两国桥、芭蕉免费区域、浜町公园、明治座外。

## 怎么读

每站正文先用普通游客能懂的话说明怎么玩，再列完整道具内容、现场证据、正确解法、错解与提示。审核单另存，设计者不能替审核者宣布通过。

每站顺序固定为：核读该站原始照片和视频 → 设计 → 独立审核 → 返修 → 审核通过 → 提交并读回GitHub → 开始下一站。没有完成的环节照实记未完成。资料清点与通用方法研究可以提前做，但不能提前放行后面的关卡。

## 通过是什么意思

本目录的“设计审核通过”只表示：原始媒体能支持关键现场输入，玩法和解法完整，独立审核者未找到阻断问题。现场游客盲测、真实队伍耗时和商业运营验证均须另外记录；没有运行就写“未进行”，不以模型推演冒充。

三项主门分别判定，不取平均：

1. **玩法：**玩家要识别、比较、排除、组合或动手改变材料，不能整站只是抄字、数数、听介绍。
2. **场景融合：**眼前的结构或空间关系必须决定解题动作。
3. **场景不可替代：**换个普通地点，只改地名和数字，原题不能原样成立；正式发给玩家的材料不能提前包含全部现场答案。

本项目只使用公共可达区域和自带纸件。实际场景不够支撑某种玩法时，改机制，不补写不存在的设施。
