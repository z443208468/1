## 不可丢失的用户要求
- 五处核心场景：纽扣博物馆 → 两国桥 → 芭蕉纪念馆及免费户外区域 → 浜町公园 → 明治座外观。
- 以真实场地及历史为约束创作虚构故事；人物行动、谜题、跨站因果同时成立。
- 旅游娱乐定位；不以自杀、死亡悲剧或无趣的创作说教充当悬疑。
- 必解内容不依赖额外门票、预约馆内、宗教行为或未经许可占场。
- 不新增必须取材的景点；明治座不是获准使用的剧场舞台。
- 对标《魔都迷踪》但不复制原题；文字完成不等于现场与商业验收完成。
- 先保存研究，再保存逐站实拍对照，再研究桌游/TRPG等设计方法，最后综合设计；保留否决记录，禁止新稿覆盖旧证据。
