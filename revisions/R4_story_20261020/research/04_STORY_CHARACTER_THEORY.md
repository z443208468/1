# R4 故事与人物研究收口：从资料纠错到人物事件

日期：2026-10-20。用途：为**锁定 R3.1 五关机制、仅改故事**提供创作与审查依据。本文件是研究结论和本项目推论，不是已经批准的新故事。

本轮复核了仓库 `methods/03_STORY_PLAYER_EXPERIENCE_R3.md` 和 `methods/02_GAME_DESIGN_RESEARCH.md` 的全部文字。它们已保存作者、出版社、大学来源以及此前实际阅读范围。因此，下面注明“既有研究”的条目，表示这次读到的是项目中已核实的研究记录，**不伪称本轮重新取得每一篇原文**。本轮另由主线程重新打开并核对了 S01、S10、S11、S12 的公开原文；该复核与早先项目记录分别注明。子任务独立学术插件检索未收到结果，不列为新增证据，不能把一次请求写成一次成功研究。

## 2. 什么才是一个故事事件

下列是依据 S01 并结合本项目限制建立的工作判据。

一个场景不应只告诉玩家一项事实，而应呈现：某人为了得到东西采取行动，世界或其他人给出与预期不同的反应，于是他必须付出代价、改变方法或重新选择。变化应发生在人物关心的价值上，例如信任、自由、归属、承诺、机会、尊严、关系的亲疏。它不必关乎生死。

“原来是 1995 年以后”是事实发现；“这份发现让我们先前追赶的人不再像嫌疑人，而使一直委托我们的人的说法出现破口”，才可能成为事件。这里的后半句只是**事件结构示例**，不是批准某位角色撒谎，也不是新增谜题。

给每一关写五格：

| 五格 | 作者必须给出的具体内容 |
|---|---|
| 行动 | 进入本关前，谁主动做了什么，而非只把一张纸递出来？ |
| 期望 | 他相信这个行动将得到怎样的具体结果？ |
| 反作用 | 谜题的固定答案或另一个人的行动如何破坏该期望？ |
| 被迫选择 | 已经不能照旧继续，他必须在什么有代价的选项中行动？ |
| 价值变化 | 出关后，人物的哪一种关系、资格或机会发生可感知变化？ |

若第四格只能写“去下一个景点再看”，第五格只能写“又多知道一条历史”，这一关仍然主要是资料节点。不是每关都必须巨大反转，但每关至少应让某一股力量增强、衰退或改变方向。

## 3. 鸿沟应改变行动，不能只制造答错

“鸿沟”的项目工作定义是：人物按照自己对世界的理解行动，结果暴露其理解与实际情况之间的差距。戏剧推进来自他如何回应，而不是来自作者每隔几分钟宣布前一页有误。

R3.1 的问题可以写成一条重复公式：对手提出错误结论 → 玩家纠正 → 对手换一个错误。对手没有独立有效的目标和应对行动，因而不像一股会抗衡主角的力量。提高他的奖金、履历或口气，不能补足这个缺口。

改写时，每一个错误判断都必须能够解释为以下之一：信息不完整形成的合理推断；当事人为保护某件东西选择的策略；两个真实目标的冲突；正确事实被套进了错误用途。不能让专业人士为了给题目让路连续犯常识错。**人物可以误导；可观察事实、规则和判题标准必须诚实。** 该原则属于本项目公平性设计，来源参考 S04、S06、S07。

S10 提供了互动叙事上的重要修正：不能为了保住作者的惊奇，否定玩家刚才明确选择的行动。可采用“你确实做成了这件事，但它也导致了这一后果”的结构；副作用仍要由已有局面产生。这能让固定谜题答案既有效，又推动新冲突。

递进也不等于连续增加新秘密。前三站应使同一个核心问题越来越难处理：先出现一个可理解的异常，随后旧解释经不起证据，最后发现“即使解开地点，也不能按原计划完成目标”。后两站才有机会从查明情况进入处理关系和兑现承诺。

## 4. 先造能行动的人，再给他背景

**S12 原文提炼：**麦基把欲望解释为人物主动追求外部目标，把需要解释为人物内部的缺失；人物的选择、行动和反应生成事件，改动事件也须检验人物是否仍相符。他同时限定，需要的设计主要服务于要求复杂人物的作品，并非每种动作英雄都必须有内在缺失。

**本案采用：**先决定人物具体想得到什么、为何用当前方式行动，再检验五关事件；不为制造弧光强塞创伤。

以下人物表是本项目综合框架，不将所有栏目都归为麦基唯一模型。

| 项目 | 好的写法需要回答 | 应避免的空写法 |
|---|---|---|
| 外在欲望 | 此刻希望在今天完成哪件看得见的事？ | 想成长、想证明自己 |
| 内在问题 | 什么习惯使他反复把关系或事情弄坏？ | 性格内向、小时候很惨 |
| 害怕失去 | 若今天失败，他具体失去什么，又为什么在意？ | 单纯把奖金加大 |
| 错误应对 | 他会用怎样的主动行为保护自己，因而惹出麻烦？ | 等游客替自己查资料 |
| 能力 | 他至少在哪件重要事情上确实有用？ | 自称专家却处处认错 |
| 关系债务 | 他曾向另一个人作过什么承诺，或欠下一次未处理的行动？ | 开场堆一段悲惨履历 |
| 压力选择 | 当两个都在乎的东西冲突时，他先牺牲什么？ | 台词宣布自己善良 |
| 变化证据 | 最后他做了哪件开场不愿做的事，而且付出实际成本？ | 说“谢谢，我成长了” |

背景只有在影响当下行为时才进入玩家文本。观众未必先同情一个人，但可以先被他的难处、行为矛盾或有趣的处境吸引。普通游客不需要预先赞同“艺术理念”“保护作者署名”才能参与。应先给他们一个容易理解的问题，再让人物的具体行动建立感情。

S10 同时提醒：NPC 可以怀有互相矛盾的愿望，作者却不能自动规定游客也有相同的内在矛盾。因此，可以写澪害怕失去某段关系，却不能强写“玩家此时一定因背叛她感到内疚”。玩家文本应给事实、行动与选择空间，感受由玩家形成。

人物弧光也不等于“坏人变好人”。本案可以使用：同一愿望保留，但处理愿望的方法改变；两个角色原有的关系解释改变；某人终于兑现一个一直想兑现、却害怕承担后果的承诺。变化要靠动作和选择体现，不靠终章长独白补发。

## 5. 悬念、好奇与惊奇分别承担什么

下面是本项目采用的叙事工作区分，不假称从 S02 的问卷直接推出。

- **好奇**针对缺失的原因：这件反常的事为何发生？人物为什么这样做？玩家愿意继续，是因为想补齐一个具体的信息缺口。
- **悬念**针对尚未兑现的结果：我们已经知道有人要做什么，却不知道能否成功、成功会伤到谁。找到明治座可以很早被猜到，尚未解决的结果必须足以继续牵引。
- **惊奇**是对已有理解的突然修正：新事实使前面的材料有第二种合理解释。它必须由前面已经存在的证据支持，不能临时引入陌生幕后人。

五站不宜都靠“下一站在哪里”吊胃口。玩家知道路线并不会自动破坏故事；开放路线本就应该清楚。真正需要保留的是**为什么走这条路线、某人到底在完成什么、我们帮助他以后会发生什么**。最后如果只是公布用户早已知道的剧院名称，起点承诺的核心问题就没有得到相称回报。

误导审查应记录四列：玩家看到的真实材料；人物作出的解释；另一种解释在何处已被允许；何时有足够证据排除错误解释。任何必须靠“其实此前没给你的还有一页”才能成立的核心翻转，都应退回重写。S11 对本案最有用的约束也是这一点：解决和发现要从已经发生的情节内部长出来，不能由末尾空降的权威直接宣布。

## 6. 玩家关系必须从开场即成立

据 S03、S04、S05、S07，本项目应把玩家视为对事件有用的行动者，而非替 NPC 验收五份作业的人。

开场需要交代五件事：玩家现在以什么身份参与；与主角有何直接关系；为什么由玩家行动比当事人自己行动更合理；此时能做哪件小而明确的事；帮助以后有哪些可见的利益或情感回报。不要用“你们天生就是最好的调查员”跳过角色逻辑，也不要终局才突然说玩家一直是演员。

参与感不要求新增机关或扩展世界。固定答案仍可改变谁掌握主动、谁必须承认什么、谁的计划能够继续、某项承诺是否被实际履行。现有第三站 `share/challenge` 应当允许两种有理由的处理策略，且严格保留原机械后果；故事后果可以不同，但不能暗改提示数、判题难度或完成资格。

NPC 的行动需要与玩家解谜同步发生。可以用现有过场文字呈现某人撤回一条承诺、停止一个原计划、交出行动权或承认一个已被证据逼出的事实；不能把全剧重要事件都安排在玩家看不到的地方，最后给一段录像结算。

## 7. 高潮：让已得信息参与一次不可替代的完成

根据 S01、S03、S04 和本案限制，终章应同时结清三笔账：开场承诺的事件结果；人物关系或行动方式的变化；五关得到的材料为何缺一不可。纪念景片是承载回报的物件，不应独自承担高潮。

既然第五关机制被锁定，高潮的创作位置是：**同一套最终回执和景片，究竟让谁完成什么原本做不到的事。** 这件事应在开场已被期待，中段曾被重新理解，终章才真正兑现。让一次排列和归位具有关系或行动意义，是改故事；另加最终密码、隐藏部件或新的现场互动，是改机制。

温暖结局也需要代价。代价可以是放弃控制、承认一次责任、接受别人有不同愿望、公开履行自己作过的承诺；无需凶杀、自杀、失踪危险或强煽情家庭创伤。对手不必被击败羞辱，主角也不必获得所有想要的东西。

## 8. 对 R4 的放行问题

1. 把五个景点名称全部拿掉，是否仍有一个可以完整讲述、值得追查的现代事件？
2. 开场三分钟内，游客能否用一句话说出自己关心的未知问题？
3. 主角至少一次主动行动是否使事情更复杂，而非一直等待玩家补救？
4. 对手的行动是否合理且有效？是否有能力改变主角计划？
5. 五格事件表是否至少在关键中段与终章出现真实的价值变化？
6. 即使玩家提前猜到明治座，是否还存在一个足以继续走下去的问题？
7. 每个关卡的固定答案是否造成可见后果，而不是仅作为解锁后段文本的门票？
8. 终章真相能否回指开场和中段的已见材料，不借新证人、新密码或新隐藏物完成？
9. 玩家保留或分享信息的两种路径，是否都有合理解释和完整结局？
10. 是否偷偷复活已否决的档案修复、署名纠纷、玩家是演员或死亡悲剧？若有，退回。
11. 是否能逐字段证明 R3.1 操作、答案、道具用途、分支机械后果没有改变？若不能，退回。
12. 完整稿是否有足够短的现场必读文本，而不是用大量背景解释代替事件？

**收口结论：下一步应进入人物与核心事件设计。不能再把新增理论数量当作创作质量的替代指标。** 先用上述问题淘汰只有主题没有行动的提案，再让人物在五个已锁定机制中遇到逐步升级的后果。真实性由史料和机制边界承担，吸引力必须由人物行动与兑现承担。
