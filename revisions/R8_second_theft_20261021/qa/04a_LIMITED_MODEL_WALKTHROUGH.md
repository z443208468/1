## 1. 只看开场后的即时理解（在任何调查和后续页面之前落笔）

### 看到了什么

- 开场主区 `00 / 你手里已经有什么`：我原本参加城市试景工作坊；纸包有三张景芯片，标签为“试景片，活动结束由佐伯灯收回”。
- 同区：鹭泽透称旧剧场景匣昨夜被拆，要求“现在封袋，交给鸣海，按返还失主处理”。两幅图的缺口和折痕没变，页面问“看不见，真的等于被拿走吗？”
- 左侧持续状态：`真景芯 · 由你保管`、`外框 · 仍在鸣海处`、`转交 · 尚未授权`、`对手要求 · 要求正面确认`。
- 开场规则：“所有站点和联系人从开场可用”；“实地模式先给观察任务；桌面模式提供取材转绘参考”；可随时开备用板，提示免费，直接答案记为辅助。
- 可见行动：`暂不转交`、`询问三人`、`检验全案 / 提前解案`、`提前结束`；正文按钮 `开始试景`、`先问清借用与持物`、`现在拒绝转交`。

### 我此刻认为的身份、控制权与下一动作

- 身份：参加工作坊的临时持物者，被卷入“是否失窃、该归还谁”的争议；目前没有证据让我认定鹭泽就是失主。
- 控制的东西：纸包中的三张景芯，以及是否把它们交给鸣海的授权；外框不在我手上。
- 为什么可以拒交：现有标签要求活动结束还佐伯，鹭泽却临时要求按失窃返还处理；照片只显示看不见，没有连续过程。拒交是暂停有争议的交付，保留核查机会。
- 我理解的目标：保住景芯，检查照片与实物/地点材料，判断“失窃”说法与交付关系，再决定怎样处理。
- 下一动作：先拒绝转交，看它是否真的改变交付状态；再自愿继续检查材料。暂不选桌面模式、不打开提示/备用/史料。

## 2. 拒交与提前结束

- **看到了什么 → 认为可做什么：** 开场正文 `现在拒绝转交` 可立即执行；我认为不需要先解题。
- **实际点了什么：** 点击 `现在拒绝转交`。
- **反馈：** 左侧从 `转交 · 尚未授权` 变成 `转交 · 已暂停`；顶端提示“转交已暂停。真正的三片景芯仍由你保管；这项行动本身不证明全案真相。”没有要求先走站点，也没有假装我已解开照片。
- **下一理解与操作：** 我想检验停在这里是否也算真实的处置结果，点击左侧 `提前结束`。
- **反馈位置：** 结果页 `EARLY REFUSAL / 你已经拒绝转交`，正文“景芯仍在你手中，这一次错误取物没有发生”“你还未必知道图是怎样做的，或三个人各自隐瞒了什么”；另有“这不是‘没通关’”和“未检验原始记录时，系统不会宣布全案已证”。
- **判断：** 拒交给了明确、可保持的处置成果，并保留事实层面的未知。`保存当前结果`、`自愿继续调查`、`主动查看作者真相（剧透）` 三个动作明确区分；没有打开真相。
- **实际下一动作：** 选择 `自愿继续调查`，然后前往 S03。继续是自选，而非拒交被撤销后的强制补站。

## 3. S03 实地初始题面（未开提示、备用或资料）

- **进入方式：** 自愿继续后，直接点左侧 `03 · 可自由查看 / 芭蕉史迹展望庭园（免费屋顶）`。未切换桌面资料；页面显示 `现场任务；到场未认证`。
- **任务原文位置：** S03 顶部 `古人没有活在这张照片里`；现场任务框要求比较“坐像、像座说明和整体环境”，并提醒“注意纪年属于哪一句话”。下方要求“读取像座所见的纪年，将它放到对应载体”。
- **实际可见图：** 全套纪念设施的示意图，铭牌区域是空白；没有在图上读到年代。四张卡依次显示“包含完整设施的照片 / 当代铜像 / 后世模写 / 肖像原画”。
- **已经透露的信息：** 第一个下拉题的题干直接写 `1995 年标记属于哪一层？`；第三个题又问 `像座上纪念设施的年代`，候选项有 1680、1930、1995。即使不看现场、不点任何辅助，我也已从题干得到要找的年数 1995。这是初始题面上的明确泄露，不能算自己观察得到的年代。
- **尚未知道：** 铭文原句、1995 具体指何种建造/设置/复制事件；四张卡连接要求的方向；照片的实际拍摄年；B 的昨夜失窃到底怎样形成；三人的持物与授权记录；真正该把景芯交给谁。
- **我此刻能推理但没有检验的部分：** 若照片包含一件 1995 才有的设施，`1930 年未经改动的实拍` 便有冲突；这一日期本身不能判景芯所有权或昨夜是否丢失。页面把 A、B、交接要求分开，有助于避免一次日期判断吞并全部结论。
- **实际下一动作：** 不提交 S03，不以猜测冒充到场观察，转去 `询问三人` 查持物和交接证据。

## 4. 一次核心调查：按来源索取三人的记录

全程保留默认 `暂不向鹭泽公开`。联系人页说明“取到原记录不自动等于告诉鹭泽你已经查到什么；公开质疑是另一项行动”，因此我把索取副本理解为查证，暂未亮牌。

1. **佐伯灯卡 → 索取同次原始记录。** 她的开场说法是“片是我借给你们的，按标签还我”。按钮后展开 `L借用单`：三片现代景芯、借出方与归还对象都是佐伯，鹭泽只获外框展示许可。`D完整制作记录` 显示先有现代纪念庭园原图，鹭泽提出 1930 主张后，灯仍提供过遮掉现代参照的修片。我的理解：她有归还依据，但对误导销售也有参与，不能因为她是归还对象就免去这段记录。展开文本明确“片仍在你手中，直到你明确执行归还”，没有把看记录当成已归还。
2. **鸣海航卡 → 索取同次原始记录。** 我优先找他，是因为他是演示记录拍摄者且保管外框。展开 `D-17同次连续演示记录`，六格从圆片在槽、前遮片进入、不可见、退出、重新可见，到旁视仍在原槽。原图里的缺口、框角、桌布折痕继续出现。我看到六格示意图里的遮片前后移动、圆片位置不变。旁边特别说“D-17编号只辅助对应”。我的理解：这不是仅证明一种可能手法，而是借共同标志与连续过程把 B 接回同次演示。反馈还把左侧外框状态改成 `鸣海暂停交付`。
3. **鹭泽透卡 → 索取同次原始记录。** 展开 `A销售主张`、`B所谓失窃` 与 `授权回答`。后者说明他拿不出灯转让景芯的记录，转而提出“先交鸣海暂存也行”。我的理解：暂存也不应该绕过原借用关系；我的拒交仍有效。卡片说明只有明确公开质疑才会改变对手要求，我这时仍没有公开。

### 进入结案页之前的判断

- B 对应 D-17 同次未裁演示记录，不是 S03 的年代或我今天能否模仿。
- 归还对象与转让许可对应 L + D。
- 不必为证明 B 而补走五站；我认为已经有依据检验核心事件。
- 未实地核验 S03、未确定完整设施的具体历史日期来源；A 的独立年代检验还没做。
- 未看 `主动查看作者真相（剧透）`，未使用提示、完整解法、备用观察或资料按钮。

## 5. 提前解案：第一次提交

- **看到了什么：** 点击左侧 `检验全案 / 提前解案`，出现 `CASE / 提前解案合法有效`。文案说“你无需补齐五站”“1930 年代主张是独立核验，不能代替昨夜事件的证据”。
- **我认为可做什么：** 先把 B 与归还主张分别配到已有的原记录，检验核心事件，然后明确处置景芯；不必硬填尚未实地核验的 A。
- **实际准备提交的判断（在点击检验前记录）：** B 选 `D-17 同次未裁演示记录`；归还关系选 `L 借用单 + D 制作/修片记录`；共同结论选 `历史题材不等于古物年代或所有权`。
- **反馈：** 点击 `检验核心事件` 后，顶端提示“核心取物事件已由借用、制作及同次演示记录证成。你可以现在完成处置，不必补齐五站”；题后状态为“年代主张：未核，不影响本次处置”。一次提交被接受；没有猜错后换项，也没有打开提示。
- **我的处置选择：** 现有独立记录足够质证，我不需要再演示一种手法。点击 `现在公开质疑`，页面将对手要求改为 `要求连续背面/旁视检验`，并说明“不能收回他的已知信息”。我选择 `逐项质证并归还`；其说明“公开线无需重演：借用/制作与同次原记录承担证明”，因此没有把对手追加要求当成必须满足的新关卡。
- **实际最终动作：** 点击 `把真景芯归还灯，并让鸣海归还外框`。
- **真实状态反馈：** 左侧变成 `真景芯 · 已归还灯`、`外框 · 已由鸣海归还`、`转交 · 已取消向鹭泽的转交`、`对手要求 · 本次交易已撤回`。
- **结案页位置与文案：** `RESOLUTION / 已经发生的处置`，标题 `第二次失窃没有发生`；表格显示 `核心取物：由L+D、B与D-17对照证成`、`A 来源年代：本轮未独立核验`、`先前拒交：已发生并保留；当时已止住转交`。
- **有限结论：** 我完成的是基于可见原记录的提前处置，没有完成五站或 S03 年代独立核验。结案保留这些边界，也保留灯曾协助修片的责任；没有声称所有争议已解决。
- **停止点：** 在此停止，未点 `复看真相`。截图 `work/player_early_close.png`；三人记录截图 `work/player_contacts_records.png`；均仅在 work。

## 6. 可重现的问题与最小修改建议

- **实际：** 题干显示 `1995 年标记属于哪一层？`，紧接着另一题要求选择 `像座上纪念设施的年代`。示意图中的铭牌是空白，但问题已经告诉我年数。
- **影响：** 页面要求的“读取像座所见的纪年”可被跳过。下拉里选到 1995 不能据此算现场观察成功；本次也没有据此提交。
- **最小建议：** 实地未开辅助时，将题干改为“你在像座上读到的纪年属于哪一层？”；若年代获取本身是考察目标，则避免在相邻题干或选项标题中再次明示正确年数。备用、资料或直接解法的揭示仍可按已有留痕机制发生。

### 一处尚未验证的理解疑点

S03 的“连接四张载体卡”没有在可见说明里明确连接方向。我看见卡片初始顺序是照片→铜像→模写→原画，不确定应按来源到成品还是观察物往来源连接。本次没有操作卡片，不能把此疑点判成实际失败。最小澄清可在指令中写明期望方向，例如“从肖像原画到现场照片”。
