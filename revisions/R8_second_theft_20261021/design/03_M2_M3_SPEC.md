# M2/M3联合规格 v1｜《第二次失窃》

上游：`02_SELECTED_EVENT.md`的v1.1补丁及`../qa/01_M1_INDEPENDENT_REVIEW.md`。本稿包含原联合规格及末尾v3有效修订；发生差异时以末尾修订和完整作者稿为准。本稿确定行动、证据、题目及可构建重演，不写完整对白，不宣布实地或游客测试通过。已直接查看本轮S01抽帧、S02案内图/百本杭牌、S03像座铭牌、S04导览图与体育中心照片；史料边界沿用`../research/01_HISTORY_EVIDENCE.md`及其后原像素补充报告。

## 一、共用状态与行动协议

初始`coreHolder=player`，`frameHolder=narumi`。界面常驻“暂不转交”“询问三人”“检验全案”“提前结束”；五站随时可开，不存在章锁、印章锁。默认建议路线仍为五站，不以真实时间催促奔跑。

`hold`立即令`transfer=paused`，只显示“试景片仍在你手中；事实尚未查清”。若玩家选择结束，可保存这项结果；“查看作者真相”需明确主动点击，所得状态为`spoilerViewed`，不是`caseProven`。

三个联系人均有从开场可直接请求的记录：

|对象/请求|实际交付的游戏物证|立即反作用|
|---|---|---|
|灯：全部制作、借用与修片记录|L借用单；D制作原图、一次修片及知情顺序。她承认看到1930销售说法后仍修过一次图|确认暂不允许景芯转给鹭泽；承认自己的配合，不能自动推成她全部说法可信|
|鸣海：所谓失窃当次的完整记录|N同一场记D-17的连续演示记录：放演示片、遮片连续进入、移开及同次旁视；红匣固定不对称缺口、框缘、桌布折痕在开场裁图中已可辨认。注明是**虚构角色制作的原始演示示意记录**，非本轮真实拍摄犯罪影像|发现自己的动作被称作失窃证言，暂停外框交付并保存完整记录|
|鹭泽：销售主张与授权依据|A“1930未改原拍”的销售样张；B“昨夜失窃”两图；其没有景芯转让授权的回答|要求尽快交出；若收到具体质疑则转为要求背面检验/提出买断，不继续争辩年代|

请求记录不用做完谜题。鸣海明知外框由灯寄存；一见“归灯”被改称“返还鹭泽”的具体矛盾，就暂停核对并可拒绝见证，不会因自称失主自动替鹭泽取得景芯。骗局只是一项试图得到物与误导见证的行动，不保证得逞。全部事实可以提前取得；走现场是选择亲自检验的途径。`caseProven`由**L借用关系+D制作/修片记录+N同次完整演示+B被改述的两图**相互对照获得，不由`solvedCount==5`获得。A年代反证是另一项命题，不能代替N证明昨夜事件。

每题存`draft`、`lastAccepted`与`dirty`。更改输入后清除当前绿色成功反馈，但已取得的证据留在案卷；未重新提交的草稿不更新后续判断。空答、部分对、全对分别反馈；错误可重试，不永久丢失核心信息。三级提示免费；“直接取得解法”记`assisted`，不剥夺结局。

## 二、两模式的信息差

`field`默认不给决定答案的完整参照图，给“去看哪类对象、哪些细节不要依赖”的观察任务；玩家用现场对象填补原本缺失的信息。`desk`直接显示标为“取材转绘”的参照板。实地模式可随时开备用板，逐站记`referenceMode=field|fallback|desk`。按钮不会验证到场，不强制上传照片/GPS，不把点击算作观测证据。

不公开原始路人照片；构建使用原创转绘与摘要，作者版保留照片文件名索引。若天气、视线、闭园或无障碍原因使观察不可用，开启备用后明确改变该站记录。最终回执逐站显示使用方式，不能把全开备用的体验宣传成已经完成现场观察。

## 三、五题完整合同

### S01｜它不见了，还是被挡住了？

**输入与操作：**三张同尺寸原创景芯片，分别只画远塔、高架、近柳枝。现场版不给正确叠合参照；在公共步道辨认三者前后关系，不跨车道找精确点。数字用拖动/上下移交换层次；纸件用三个错位页签标示叠放顺序，不用颜色作为唯一编码。远→近答案为`tower,viaduct,willow`，不是旧版`tower,sign,roof`。合成图必须实际按该顺序绘制遮挡，不能仅显示列表。

另有开场A/B两幅红匣图和一枚**带斜线边的演示圆片**。玩家在纸上移开前遮片，或在UI拖动遮片，看见圆片仍在原槽。提交解释为`occlusion_possible`：图片能够由遮挡造成，尚不能仅凭此认定昨夜没有盗窃。

**答案依据：**本轮`纽扣博物馆.mp4`（44.954秒）19.3秒等抽帧可见近柳枝、中高架、远塔；`IMG_3579`仅为旧报告的素材名，不当作本轮原件。工艺联系仅为图画纽扣分层，不称精确复原某馆藏。**提示：**①找前后，不读广告；②先找最远的塔，枝条位于眼前；③远塔→高架→柳枝；移开遮片，圆片仍在。**错误反馈：**“你将远塔压到高架前；再看哪一物遮住另一物”；“能制造消失画面，还不能证明当夜事件身份”。

**状态后果：**获得`imageNotEquivalentToRemoval`，玩家可直接带此问题问鸣海；鹭泽不会自动得知。它在终局转为玩家亲自操作的反证。树枝季节变化或塔不可见启用备用；不依赖枝叶数量或精确重合。**场景等级：**拟S2，取材支持原型；馆外工艺与特定街角的排他必要性仍未证明，不能报S3已过。

### S02｜是两条河，还是两个名字？

**输入与操作：**无文字、无北箭头的主支河底图，两个同尺寸桥条，以及三个可放置桥位槽。基准图为主河纵向、支流从左上汇入；跨主河槽在汇口下方，跨支流槽在汇口之前，第三槽横跨汇口本身为错误候选。所有名称放在独立直立卡片上，不随旋转泄底。玩家观察现场河口或公开案内图，把“両国橋”放跨主河槽，把“柳橋”放跨支流槽；两桥条尺寸相同，不能靠宽窄直接对号。

然后把“隅田川”“稲瀬川”分别放在**实景所在/戏中称呼**，并选结论`same_view_different_name`，而非`left_tokyo`。史料卡说明所指是国立剧场解说的特定借景，不泛化一切稲瀬川作品。

**提示：**①先分主河与汇入支流；②柳桥横跨支流，不能把它当主河下一桥；③両国橋跨隅田川，柳橋跨神田川；实景隅田川/舞台稲瀬川。**错误反馈：**“这会把柳桥安到主河上，与案内图的连通关系不符”；“舞台名并不证明这组画面在远方拍摄”。

**状态后果：**玩家排除“照片证明携物人已离开东京”的推断，主动决定不按鹭泽说法远追；获得西两国戏棚的有来源短卡，为S05埋下同一传统的线索。原件IMG_3598、3607；额外IMG_3608可作文化观察，不另加站。**场景等级：**拟S2→S3；若UI预先给完整标名地图，则降为S1。现场不要求看到旧木杭、不靠水流方向、不照古画精密配准。

### S03｜照片里的“古人”是哪一层？

**输入与操作：**四张图像身份卡：芭蕉肖像原画、后世模写、当代铜像、包含铜像及现代庭园的销售图。现场版让玩家观察像座说明并提供逐词双语词表；不会默认把完整译文当作已观察。备用可查看有出处的全文摘要。将四卡连接成`portrait→copy→bronze→photo`，再把“平成七年四月/1995年4月”标记放在**铜像/设施形成**上，把“不早于1995”区间括号放到明确记录完整现代设施的照片，而非芭蕉生平上。

最后从三张主张中只撤掉A：“此图是1930年未经改动的现场照片”；保留“昨夜是否盗窃”“物件归谁”为待其他证据证明。以相似绘画代照片时不能用这个下界，题面须明确所比对的是完整现代设施实拍的声称。

**提示：**①把人、画像、复制品、实体分开；②像座说原画经过模写后制成铜像；③原画→模写→铜像→照片；1995是下界，只反驳1930未改实拍。**错误反馈：**“你把纪念设施年代填给历史人物”；“重演/借用记录尚未讨论，不能据1995跳到昨夜不存在盗窃或确定归属”。

**状态后果：**获得`sourceClaimDisproved`；向灯出示矛盾后，她具体承认知情后修图；已提前索取D者直接对照，不重复演一遍‘首次坦白’。**场景等级：**拟S2；IMG_3627让现场不再只提供年份，但英文全文备用会降低现场信息独占性。像朝向完全不参与答案。题面摘要保留原画归属的“相传/据铭牌”，不将传述升级为作者已认证。

### S04｜镜头在哪里，物件就在哪里吗？

**输入与操作：**匿名局部图仅保留前方游具轮廓和后方菱格立面。现场辨认后，在原创公园拓扑上放“相机”与“被拍建筑”：河侧为图上边，左大场地、右体育中心，游具在体育中心右侧，主入口在下边；这些是相对关系而非米制测绘。相机仅需选“游具一侧/体育中心一侧”，不要求到唯一坐标。答案`camera=playground_side,subject=sports_center,direction=toward_sports`。

玩家再用箭头标“记录取景的方向”；“运输/交付方向”仅是题面允许误选的解释，不写成鹭泽此前真的指定体育中心收件，不额外给他添加一个错误。用同次N记录连接开场两图，找到在圆片仍固定时移动的前遮片。选结论`record_is_demonstration`的根据必须是N同一D-17连续记录及预置画面特征，不能只凭今天可以重演，也不能只凭编号相同。

**提示：**①认前景与后景，别把镜头端与被拍端倒置；②案内图把游具与体育中心放在同一侧相邻，画中菱格立面在后；③相机在游具一侧朝体育中心；这是取景，N的前后格证明当次为演示。**错误反馈：**“你的箭头从被拍建筑出发，与画面前后关系相反”；“能重现一种可能性≠已证明原事件身份，请看同次完整记录”。

**状态后果：**鸣海撤回“失窃目击者”身份，外框继续暂停；获得终局重演所需的前视/旁视区分。IMG_3633/3634/3636支持现代关系；1929公园开园只在来源时间层使用，不能证明此镜头。**场景等级：**拟S2→S3的现代取景证据；历史专属性仍偏弱。无须进入游具、体育中心、运动场或河岸围挡；儿童聚集时使用备用。

### S05｜旧名字能替谁取得这件东西？

**输入与操作：**来源卡给西两国戏棚、喜昇/久松/千歳/明治座沿革，五条短片分别进入“名称延续”与“地址变化”两轨；正确名称链仍为喜昇→久松→千歳→明治，1928只入迁址轨。现场只核对今日实体名，不假装外墙有完整年表。此整理限短收口，不能独占终章。

真正终题为并列的三项质证：把A1930主张配给S03形成下界，把B昨夜两图配给N同次完整记录，把“交给失主”配给L借用单+D记录；反驳`old_subject_implies_old_owned_object`。正确结论为`historical_subject≠object_age_or_title`，并在实际操作区选择物件去向。不要再填写七个旧答案领取结局。

**提示：**①旧名、旧址、物件来源分开；②1928改变地址，不新造第五个名字；③按上述两轨，三条主张分别用A年代/N演示/L+D借用制作记录处理，景芯归灯、空框由鸣海归还。**错误反馈：**“剧院传统确实延续，却没有来源证明你的景芯曾属于旧剧场”；“这项证据回答的是另一项主张”。

**状态后果：**玩家操作将`coreHolder=akari`、`frameHolder=akari`，取消向鹭泽的本次转交并保留三方责任记录。这里只做游戏内物件位置变化，不要求现实邮寄/交给剧院。**场景等级：**S1为主；外观可确认现实实体，完整沿革来自卡。终局行动的成立不等于明治座外场专属性已解决。

## 四、两项独立选择与四种结果

选择一`disclosure=announce|quiet`，可随时改为announce，但已发出的质疑不能撤回NPC记忆。选择二`resolution=expose|replay`，在结算时确定。

|组合|NPC知识与反应|玩家实际完成、保留的结果|
|---|---|---|
|announce+expose|鹭泽已知道被查，先要求背面/谈买断；不能再装不知道现代来源|逐项公开证据，拒绝买断，撤销转交；保留其追加检验要求|
|quiet+expose|鹭泽直到成套质证出现才知道玩家已取得N/D；随后改价或取消|一次公开相互独立的证据，保留其先前未经追加检验的交出要求|
|announce+replay|鹭泽识别这可以是遮挡，要求旁视或拒作判断|玩家给鸣海完成重演与旁视验证；不写“骗过了鹭泽”|
|quiet+replay|鹭泽只可先确认前视图与旧图的**可见状态相似**，不强迫他认定现在发生盗窃|打开旁视证明不可见≠离开；其前视确认与N同次记录并列保留，不把确认升级为认罪|

四组合都可取得全案事实与物件归还；不同的是披露顺序、对手检验策略、保留的交涉记录与是否实际重演。受控重演不是售假、抓人或现实合同。若先提前拒交再继续，结尾显示此前已保全，不抹去其作用。

## 五、可实际实现的受控重演

开场就提供一套原创演示件，数字与打印同几何：底板160×90mm，演示圆片中心(80,45)、半径8mm；可移动前遮片矩形宽24mm、高42mm。圆片固定在底板槽内；前遮片从左移至x=68mm、y=24mm时完全挡住圆片。界面用viewBox 320×180按2倍坐标绘制：先底板、圆片，再遮片。前视按钮不显示层级标签，层级控制在画框外。

玩家必须先把真正三张景芯拖到“由我保管”区，操作独立的斜线边演示圆片。然后移动遮片到遮住圆片的位置，再按“查看旁视/分层展开”；数字显示层间错位及未移动的圆片，纸版直接抬起前遮片。**不能把圆片本体删除后播放一句‘还在’。** 在公开线仍可自愿操作，但不强制为取得事实补做。

这只证明该图像能够用遮挡生成。要证明昨夜同一拍摄实际为演示，仍需N连续记录、同一D-17场记、开场已出现的固定缺口/框缘/桌布折痕，以及鸣海对亲历的说明；构建必须实际显示遮片进入、遮住、移开和同次旁视的连续变化，开场两图由这份固定场景生成，不能只给一行“原记录证明了”。编号或同款匣子均不单独证明记录身份。重演成功条件为`realCoreSafe && demoDiskStayed && occluderMoved && sideViewOpened`；失败仅指出尚缺哪一个实际动作，不依赖五站完成数。

## 六、M4待验与真实限制

必须实际测：修改已答正确草稿不会沿用绿色成功；联系人可从首页取得全部记录；提前拒交可保存退出；提前充分检验可直接结算；4选择组合各有不同NPC反应；英文与辅助路径不丢核心信息；前遮片真实遮住固定圆片且旁视可复现；纸版抬片可见同一圆片；两模式证据板显示不同且备用被记录。

当前仅是可实现规格。Gate2不能五站统一填PASS：S01馆外专属性未充分建立、S04历史对空间动作贡献有限、S05仍主要是有地点落点的资料整理与终局。应由controller决定是否以这些负结果退回M1或标为试验版；不许通过把缺口移进免责声明后声称“强实景五关全部达成”。

## v3.0 合流后的有效补丁（覆盖上文早期细节）

1. 核心事件验收只要求B与同次D-17对应，以及返还主张与L+D对应；A年代反证独立可选，未核不挡结局且不被自动报已证。S05沿革也不是结局门。
2. 正常field题面不预给S03的1995归属/下界/唯一驳回对象，也不预给S05的证据对应。答案仍在明确辅助/解答页。历史资料展开、备用、答案型提示均保留取得来源；切回field不擦除。
3. D-17采用六格：固定圆片与遮片移入、遮住、移出、再现及同次旁视；缺口、框角、折痕同源连续，不用编号本身代替证明。
4. 核心处置和已公开信息写入完成记录，改题草稿/恢复存档不倒回归还。新局需单独明确动作。
5. 制作完整实验原型不改变required合同；S01/S05已有依赖反例保留REJECTED，公园操作对D-17证成可被删除也保留。未实测与已失败分开。
