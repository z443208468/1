# 佐伯灯定点复核 v2

依据：`work/m1_selected_v1.md` 的v1.1。人物代理：`/root/character_maker`。仅复核灯；现代事件、文件均为FICTION。旧稿“景芯仍在灯手里、她拒交所以游客无法取物”的设定及对应台词撤销。

## 1. 当前动机与知情

她已按正常安排把三片现代景芯借给玩家，标签写明归还灯。她现在希望景芯按约回来，同时尽量不暴露自己在看见“1930未改原照”假文案后仍补过一次修片。她可以害怕承担这项责任，不能因此含糊景芯归属、阻止玩家暂停或要求继续把真物带给鹭泽。

她知道制作、借出和修片过程；只有玩家出示“昨夜失窃”材料后，她才知道鹭泽把演示改称失窃。她不能预先知道他向玩家说过的每句话。

## 2. 哪些文件公开、隐瞒与补救

**始终公开：** 包内借用标签、三片景芯清单、现代分层制作说明、外框仅供展示的原安排。玩家问“这些是谁的”，她立即确认借用关系，不拿“保密”拖延。

**她原先没有主动交出：** 未遮现代参照的来源图；含假1930文案的销售样张；她在看到该样张后仍发送遮挡修片的回复。这三项按原先后顺序保存，没有销毁。她最初只说“我做过复古展示”，回避知情后的配合。

**补救必须是实际动作：** 玩家索取完整记录，或直接问她是否知情后仍修过图，她就交出以上三项，明确哪一版由自己制作、何时看到假主张、随后做过什么。不能只说“我也有错”而继续不给材料。公开事实和暂不向鹭泽透露策略是两件事；选择受控重演也不删除这些文件。

## 3. 她付出的具体代价

她失去把自己叙述成全然无辜者的余地，必须向参与者说明知情后的修片；完整记录留在玩家手中，不能在景芯归还后收回或删改。她停止为鹭泽继续补图，也不再要求玩家以替她保密来换取尾款。尾款是否追回仍是未定结果，不写成自动获得的奖励，更不临时增加罚金或法律后果。

## 4. 提前直问与拒交

问“是不是他的赃物”：她答“不是。你们拿的是我借出的试景片，按标签还我就行。”这足以支持玩家暂停；尚不自动证明昨夜失窃图怎样制作。

问“你是不是也参与骗人”：她先区分正常复古制作与知情后修片，再承认后者并交记录，不等第三站。玩家提前问清，后面的相关场戏改为核实与补充，不重演一次假惊讶。

玩家拒交：她确认景芯仍由玩家保管，本次取物已被阻止。她可以邀请玩家继续拆解假现场，不能宣称不走五站就不算阻止成功，也不要求真物参加重演。

可用台词：“我没有把景芯卖给他。但那个假年份出现以后，我还替他改过一张图。这一段也给你们。你们不必先相信我，才能拒绝替他拿东西。”

## 5. 复核结论

持物冲突已修复；灯的隐瞒有具体行为和损失，提前披露路径成立。她的坦白不能被年份自动推出：1995只约束某份来源图，不能否定“昨夜”。本轮同意按此人物模型进入机制实验，不认证场景依赖、终局操作或游客吸引力。
